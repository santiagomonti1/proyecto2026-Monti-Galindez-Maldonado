# Filmoteca

Diario personal de películas: una aplicación web donde los usuarios registran las películas que vieron, las puntúan, escriben reseñas y llevan un historial de su actividad como espectadores.

## Autores

- [Monti, Santiago]
- [Maldonado, Luis Bautista]
- [Galindez Quintana, Baltazar]

## Descripción del proyecto

Filmoteca permite a un usuario:

- Buscar películas en un catálogo, donde se puede ver su informacion (descripcion, autor, genero, etc)
- Marcar películas como vistas y asignarles un puntaje
- Escribir una reseña personal de cada película
- Ver un diario/historial cronológico de las películas vistas
- Ver un perfil con estadísticas (puntaje promedio, película favorita, historial)
